# LinkTracker

LinkTracker – Telegram-бот, который отслеживает изменения на веб-страницах и оперативно информирует пользователя о них.

## Реализованный функционал

### Bot
В приложении `bot` реализована обработка следующих команд:

- `/start` — начало работы пользователя
- `/help` — вывод списка доступных команд
- `/track` — начать отслеживание ссылки
- `/untrack` — прекратить отслеживание ссылки
- `/list` — вывести список отслеживаемых ссылок
- `/list <tag>` — вывести список ссылок, отфильтрованных по тегу
- `/cancel` — отменить текущий сценарий ввода

Также реализована обработка неизвестных команд: бот отправляет сообщение с рекомендацией использовать `/help`.

Для команд `/track` и `/untrack` реализован пошаговый сценарий взаимодействия с пользователем.

При первом сообщении пользователя бот отправляет приветственное сообщение.

### Scrapper
В приложении `scrapper` реализованы:
- регистрация и удаление Telegram-чата
- добавление, удаление и получение отслеживаемых ссылок
- проверка обновлений по ссылкам GitHub и StackOverflow
- отправка уведомлений в `bot` через HTTP endpoint `/updates`

## Конфигурация

Конфигурационные данные Telegram-бота, github, stackoverflow хранится в файле .env и не коммитится в репозиторий.
