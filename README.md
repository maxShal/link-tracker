# LinkTracker

LinkTracker – Telegram-бот, который отслеживает изменения на веб-страницах и оперативно информирует пользователя о них.

## Реализованный функционал

В классе `TelegramBotService` реализована обработка следующих команд:

- `/start` — начало работы пользователя
- `/help` — вывод списка доступных команд
- неизвестная команда — сообщение об ошибке с рекомендацией использовать `/help`

Бот обрабатывает только команды (сообщения, начинающиеся с `/`).  
На обычные текстовые сообщения бот не отвечает.

При первом сообщении пользователя бот отправляет приветственное сообщение вне зависимости от содержимого сообщения.

## Конфигурация

Токен Telegram-бота хранится в переменных окружения (Environment Variables) и не коммитится в репозиторий.
